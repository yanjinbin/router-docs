Mihomo YAML 本地客户端/软路由 配置差异转换

两类配置的大部分内容可以共用：代理节点、规则、DNS 分流、fake-ip-filter、sniffer 都应保留。真正需要切换的是运行环境相关项，尤其是 find-process-mode 与 tun。下面的工具支持上传 YAML、自动识别、互相转换和下载。

保留内容

代理节点、proxy-groups、rules、rule-providers、DNS 策略、fake-ip-filter、sniffer 和外部控制配置默认原样保留。

修改内容

转换器会替换 tun 顶层块，并把 find-process-mode 改成目标环境需要的值。

使用建议

转换后先保存为新文件，不要覆盖原始 YAML。上传到 Nikki 后按页面提示选择、重载、启动，再去 Dashboard 看日志。

关键片段对照
转换器主要替换这两段

软路由 Nikki / OpenWrt

find-process-mode: off

# TUN（Nikki 托管模式）
tun:
  enable: true
  stack: mixed
  device: nikki
  auto-route: false
  auto-redirect: false
  auto-detect-interface: false
  dns-hijack:
    - any:53
    - tcp://any:53

本地 Mihomo 客户端

find-process-mode: strict

# TUN（本地客户端配置）
tun:
  enable: true
  stack: mixed
  auto-route: true
  auto-redirect: false
  strict-route: true
  auto-detect-interface: true
  dns-hijack:
    - any:53
    - tcp://any:53
