immortalwrt v25.12 必装插件

为 ImmortalWrt v25.12 推荐的必装插件与主题，包含 Nikki 透明代理、Bandix 面板、eqos 流量控制及经典的 OpenWrt 官方主题。

插件名称 功能描述 获取方式 推荐度
Nikki Mihomo 强大的透明代理客户端 第三方软件源 (GitHub) 必装
Bandix 轻量级网络流量监控面板 GitHub Release 下载 必装
eqos 简单易用的宽带流量控制 官方软件源 必装
luci-theme-openwrt 经典美观的官方主题 官方软件源 必装
Nikki
透明代理客户端 Mihomo 核心
  • GitHub 仓库: nikkinikki-org/OpenWrt-nikki
  • 中文说明: README.zh.md

1. 添加软件源（只需运行一次）

wget -O - https://gh-proxy.com/https://github.com/nikkinikki-org/OpenWrt-nikki/raw/refs/heads/main/feed.sh | ash

2. 安装

你可以从 shell 执行命令安装或者从 LuCI 的软件包菜单安装。

对于 opkg 系统：

opkg install nikki
opkg install luci-app-nikki
opkg install luci-i18n-nikki-zh-cn

对于 apk 系统（新版 ImmortalWrt）：

apk add nikki
apk add luci-app-nikki
apk add luci-i18n-nikki-zh-cn
Bandix
轻量级网络流量监控面板
  • 官方文档: README.zh.md

Bandix 安装需要分别下载后端和前端，建议直接将下面的提示词发送给你的 AI 助手（如 Claude 或其他 Agent），让它帮你通过 SSH 全自动安装：

请 SSH 登录我的 R5C，帮我安装 Bandix 网络流量监控应用。安装步骤如下：
1. 通过 GitHub API 从 `timsaya/openwrt-bandix` 的最新 Release 中提取适合 aarch64_generic 架构的 apk 格式安装包下载链接。
2. 从 `timsaya/luci-app-bandix` 的最新 Release 中提取 all.apk 格式的前端包下载链接。
3. 使用 `wget` 或 `curl` 将这两个安装包下载到路由器的 `/tmp` 目录下。
4. 使用 `apk add --allow-untrusted <包名>` 命令先安装后端（bandix），再安装前端（luci-app-bandix）。
5. 检查并确保相关依赖（curl, luci-lib-jsonc, jsonfilter, jshn）已安装。
6. 安装完成后清理 `/tmp` 中的安装包，并提醒我去 LuCI 的“网络 - Bandix”设置中勾选“启用”并绑定 LAN 接口。同时提醒我前往防火墙设置关闭“硬件流量卸载”及“Turbo ACC”。
