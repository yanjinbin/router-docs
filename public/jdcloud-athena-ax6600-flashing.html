京东云雅典娜 AX6600 免拆刷机指南

面向纯小白的避坑流程：先利用原厂系统开启 SSH，写入 U-Boot，再进恢复页面刷大分区和 OpenWrt factory 固件。适合出厂固件仍可开启 SSH 的库存机。

原厂版本样例JDC02-1.5.50.r2204，未联网自动升级前更稳。
默认管理地址原厂：192.168.68.1；U-Boot / OpenWrt：192.168.1.1。
必要物料MacBook 需要 Type-C 转 RJ45 扩展坞，刷大分区和固件阶段必须走有线。

先看风险

  • 刷机有变砖风险，至少确认自己能进入 U-Boot 恢复页面再继续。
  • 新机到手建议先不要接外网，避免原厂系统自动升级后堵住 SSH 开启路径。
  • 本文整理自恩山帖子和惊蛰博客，链接放在文末；具体固件版本请以作者发布页为准。
  • 如果你的出厂版本已经无法通过漏洞开启 SSH，本文的免拆流程可能不适用。

刷机逻辑

免拆刷机的依赖关系是：OpenWrt 需要 U-Boot 和大分区；写 U-Boot 需要先把文件传进路由器；免拆传文件依赖 SSH；SSH 需要先在原厂系统里通过配置漏洞拉起 dropbear。

所以实际顺序是：开启 SSH → 连接路由器 → 上传并写入 U-Boot → 进 U-Boot 刷大分区 → 再刷 OpenWrt factory 固件。

1. 原厂系统开启 SSH

  1. 用 Chrome 内核浏览器登录原厂管理页：jdcloudwifi.com。
  2. 打开开发者工具控制台，执行下面脚本，把 odhcpd.leasetrigger 指到 /usr/sbin/dropbear 并提交。
const sessionid = document.cookie
  .split('; ')
  .find(row => row.startsWith('sessionid='))
  ?.split('=')[1] || '';

async function rpc(method, params) {
  const res = await fetch('/jdcapi', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ jsonrpc: '2.0', id: 1, method: 'call', params })
  });
  console.log(method, await res.json());
}

await rpc('set', [
  sessionid,
  'uci',
  'set',
  {
    config: 'dhcp',
    type: 'odhcpd',
    section: 'odhcpd',
    values: { leasetrigger: '/usr/sbin/dropbear' }
  }
]);

await rpc('commit', [
  sessionid,
  'uci',
  'commit',
  { config: 'dhcp' }
]);
  1. 进入「路由设置 → 上网设置 → IPv6 网络设置」。
  2. 打开 IPv6 开关，把上网方式切为 NAT6 并保存，触发 dropbear。

2. SSH 连接并写入 U-Boot

电脑终端连接路由器，看到 JD CLOUD 字样即可继续。密码使用原厂后台登录密码。

ssh root@192.168.68.1

把 U-Boot 文件传到路由器 /root。macOS 可以用：

scp uboot-JDC_AX1800_Pro-AX6600_Athena-20240510.bin root@192.168.68.1:/root/

登录路由器后写入两个 APPSBL 分区：

dd if=/root/uboot-JDC_AX1800_Pro-AX6600_Athena-20240510.bin of=$(blkid -t PARTLABEL=0:APPSBL -o device) conv=fsync
dd if=/root/uboot-JDC_AX1800_Pro-AX6600_Athena-20240510.bin of=$(blkid -t PARTLABEL=0:APPSBL_1 -o device) conv=fsync

3. 进入 U-Boot 刷大分区

  1. 路由器断电。
  2. 按住 reset 插电，红灯闪烁后蓝灯常亮，再松开 reset。
  3. MacBook 用 Type-C 转 RJ45 扩展坞接网线，建议电脑连路由器 WAN 口。
  4. 电脑手动设置 IPv4：IP 192.168.1.2 到 192.168.1.200 任意一个，网关 192.168.1.1，子网掩码 255.255.255.0。
  5. 浏览器打开 http://192.168.1.1/img.html。
  6. 上传 GPT 大分区文件并提交，等待写入完成。

4. 刷入 OpenWrt factory 固件

  1. 大分区写入后，如果路由器红灯常亮，先拔电。
  2. 再次按住 reset 插电，红灯闪烁后蓝灯常亮，松开 reset。
  3. 浏览器打开 http://192.168.1.1，注意这次不是 /img.html。
  4. 上传 factory 固件并提交。
  5. 刷完后把网线插回 LAN 口，电脑 IPv4 改回自动获取。
OpenWrt 默认信息：LAN 地址 192.168.1.1，Wi-Fi 密码 12345678。首次登录后建议立刻改管理密码和无线密码。

5. 调整 WAN / LAN 口

刷好后可以把 2.5G 网口留给局域网，便于接 2.5G 交换机。经验做法是在接口管理里：

  • 从 LAN 接口里取消 lan4，加入 wan。
  • 从 WAN 接口里取消 wan，加入 lan4。

调整前先确认当前网口映射，避免远程操作把自己踢下线。

常见卡点

  • SSH 开不了：优先怀疑原厂系统已联网更新，先恢复出厂再重试；如果仍不行，可能需要拆机或其他路径。
  • 进不了 U-Boot 页面：确认 reset 时机、电脑静态 IP、网线和 Type-C 网卡是否正常。
  • 刷完红灯：换确认可用的 factory 固件版本，不要随便刷 sysupgrade 包。
  • MacBook 没有网口：必须准备 Type-C 转 RJ45 扩展坞，Wi-Fi 不能替代 U-Boot 刷机阶段的有线连接。
