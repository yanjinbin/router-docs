# Mihomo 阵营  ·  sing-box 阵营  ·  Xray 阵营  ·  经典阵营

Nikki 推荐（已有 yaml） Mihomo
原名 openwrt-mihomo · ImmortalWrt 官方收录
Mihomo 内核的轻量封装，配置文件直接托管，nftables 原生透明代理，适合已有 clash 配置的用户零成本迁移。
  • config.yaml 直接复用，fake-ip / rule-provider / dialer-proxy 全支持
  • nftables 原生集成，比 iptables 方案干净
  • ImmortalWrt opkg 一键安装
  • LuCI 界面偏简，复杂调试仍需 SSH
OpenClash Mihomo 社区最大
v0.46.x · 支持 Mihomo / Clash Premium
LuCI 重度封装，界面操作完成全部配置，内置订阅托管、节点测速、覆写规则，适合不想手写 yaml 的用户。
  • 教程最多，社区资料丰富
  • 内置覆写（Mixin）机制，订阅链接直接用
  • 依赖多，安装包较大
  • DNS 劫持逻辑复杂，偶有与系统 DNS 冲突
HomeProxy 推荐（新装机） sing-box
ImmortalWrt 官方收录 · sing-box 内核
ImmortalWrt 官方推荐的 sing-box 前端，nftables 原生，支持全协议（VLESS/Hysteria2/TUIC 等），资源占用极低。
  • sing-box 最新协议全支持（Hysteria2/TUIC/Reality）
  • nftables 原生，与 ImmortalWrt 集成最好
  • 资源占用比 OpenClash 低 30%+
  • 不直接用 clash yaml，需重新配置规则
Momo sing-box 新兴
sing-box 内核 · LuCI 前端
新兴 sing-box 前端，界面设计比 HomeProxy 更友好，支持订阅转换，活跃开发中。适合追新用户。
  • 界面直观，上手比 HomeProxy 快
  • sing-box 完整协议支持
  • 相对年轻，文档和社区资料少于 HomeProxy
NeKoBox sing-box
NeKo 系列 OpenWrt 版 · sing-box 内核
NeKo 系列（桌面端 NekoRay / NekoBox-for-Android）的 OpenWrt 延伸，配置体验与桌面端一致，适合全设备统一使用 NeKo 生态的用户。
  • 跨设备配置风格统一（桌面 / 手机 / 路由器）
  • sing-box 完整协议
  • 社区资料主要在 TG 频道，文档分散
FullCombo Shark! Xray + sing-box 小众
双内核混合 · nftables
同时支持 Xray 和 sing-box 双内核，可根据协议自动选择，覆盖所有协议场景。定位高级用户，配置复杂度较高。
  • 双内核各取所长，协议覆盖最全
  • 配置复杂，不适合入门
  • 社区小，踩坑成本高
PassWall Xray
支持 Xray / sing-box · LuCI 前端
老牌插件，功能稳定全面，ACL 规则体系成熟。支持多节点负载均衡、分流规则精细配置，社区资料多。
  • 功能成熟稳定，资料多
  • 支持 Xray 全协议（VLESS/XTLS/Vision）
  • iptables 为主，nftables 支持不如新方案干净
  • 界面略老，交互不如新插件流畅
PassWall2 Xray / sing-box
PassWall 重构版 · 更干净
PassWall 的代码重构版本，剔除旧依赖，sing-box 支持更好，推荐新装机时用 PW2 替代 PW。
  • 比 PassWall 依赖更少，包更小
  • sing-box 集成改善
  • 与 PassWall 配置不完全兼容，迁移需重配
luci-xray Xray
纯 Xray 前端
专注 Xray 内核的轻量 LuCI 前端，配置直观，适合只用 Xray 协议（VLESS/XTLS）且不需要复杂分流的场景。
  • 轻量，专注 Xray 协议
  • 分流能力弱于 PassWall/OpenClash
  • 功能较少，适合简单场景
SSR Plus SS / SSR / V2Ray 老牌
多内核支持 · 历史最悠久
历史最久的 OpenWrt 代理插件，chnroute 分流方案，兼容 SS/SSR/V2Ray 老协议，适合老设备或历史遗留配置。
  • 兼容性最广，老协议都支持
  • 不支持 fake-ip，新协议支持落后
  • 维护频率下降，新功能几乎不更新
  • 不推荐新装机首选
v2rayA V2Ray / Xray 跨平台
独立 Web UI · 跨平台
通过独立 Web 界面管理，不依赖 LuCI，Linux/Docker/OpenWrt 通用。适合喜欢统一管理界面或无 LuCI 环境的用户。
  • 不依赖 LuCI，任何 Linux 设备通用
  • Web 界面美观，操作流畅
  • OpenWrt 集成不如原生 LuCI 插件深
  • 透明代理配置比专用插件繁琐
选型建议
按场景匹配
✅ 已有 Mihomo config.yaml
→ Nikki
配置文件零迁移成本，ImmortalWrt 原生支持，nftables 最干净。本文档多机场订阅组合配置直接复用。
✅ 新装机，追求新协议 & 轻量
→ HomeProxy
ImmortalWrt 官方推荐，sing-box 支持 Hysteria2 / TUIC / VLESS Reality 等最新协议，资源占用最低。
📋 不想手写 yaml，要界面操作
→ OpenClash
社区资料最多，LuCI 界面全流程引导，订阅链接直接粘贴使用，入门门槛最低。
🔧 Xray 协议（XTLS/Vision）为主
→ PassWall2
比 PassWall 更干净，Xray XTLS/Vision 协议支持完善，ACL 规则体系成熟稳定。
⚠️ 不推荐新装机首选
SSR Plus / luci-xray
SSR Plus 更新停滞，不支持 fake-ip；luci-xray 功能偏少。老设备迁移可用，新装机建议选更活跃的方案。
🌐 无 LuCI / 跨平台统一管理
→ v2rayA
独立 Web 界面，Linux / Docker / OpenWrt 通用，适合喜欢跨设备统一管理界面的用户。
