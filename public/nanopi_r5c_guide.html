NanoPi R5C · 刷入 ImmortalWrt 完整教程

Mac 系统·TF 卡引导·R5C 作主路由·AX82U 作 AP

为什么选 R5C
SoC
RK3568B2
A55×4 · 2.0 GHz
内存 / 闪存
4 GB LPDDR4
64 GB eMMC
加密加速
AES 硬件加速
VPN 吞吐无瓶颈
入手渠道
咸鱼 ¥500
性价比合适
RK3568B2 内置 AES-NI 硬件加速单元，Mihomo 代理下 TLS 解密不走软件路径，千兆线速无压力。相比 R5S（同款 SoC 但封装更厚、价格更高），R5C 更紧凑，咸鱼二手价格更友好。
准备材料
所需物品说明
多功能拓展坞 必须 需要同时具备 TF 卡插槽（把 TF 卡当 U 盘读写）和 RJ45 网口。推荐宏碁多功能拓展坞，约 ¥60，含 TF 卡槽 + RJ45 + Type-C，一个搞定所有接口需求。MacBook 本身无 SD 卡槽和有线网口，缺一不可。
网线 必须 刷机全程必须走有线，一根普通超五类网线即可。Wi-Fi 刷机存在中断风险，不建议使用。
TF 卡8 GB 以上，Class 10。用拓展坞的 TF 卡槽直接读写，无需单独读卡器。
引导固件FriendlyELEC 官方网盘 → R5C → sd-friendlywrt 镜像。
目标固件firmware-selector.immortalwrt.org 搜 NanoPi R5C，下载 .img.gz。
balenaEtcher（Mac）etcher.balena.io 下载 .dmg 安装。
Safari 会自动解压 .gz 变成 .img，直接用即可。balenaEtcher 支持直接烧 .img.gz，不要手动解压。
阶段一 制作 TF 引导卡 约 5 分钟
1
TF 卡插入读卡器，连接 Mac
2
打开 balenaEtcher 烧录官方固件
Flash from file → 选 sd-friendlywrt 固件 → Select target 选 TF 卡（注意别选外置硬盘）→ Flash!
Mac 会弹出 Touch ID 或密码授权，正常现象，允许即可。
3
把 ImmortalWrt 固件拷进 TF 卡
烧录完成后 Mac 弹出"无法读取磁盘"提示 → 点忽略（绝对不要点初始化）。在 Finder 左栏找到 BOOT 分区，将 ImmortalWrt 固件拖入根目录，改名为 immortalwrt.img.gz。
找不到 BOOT 分区也没关系，后续可在后台网页直接上传固件。
4
在 Finder 右键安全弹出读卡器，拔出 TF 卡
阶段二 连接与启动 MacBook 网线直连 R5C
1
R5C 完全断电，插入 TF 卡
2
网线一端插 R5C 的 LAN 口，另一端通过 USB-C 转 RJ45 插 MacBook
3
关闭 Mac 的 Wi-Fi
菜单栏 Wi-Fi 图标 → 关闭 Wi-Fi。不关 Wi-Fi 会导致浏览器走 Wi-Fi 网关，永远访问不到 R5C 后台。
4
给 R5C 接通电源
RK3568 芯片硬件启动优先级写死为 TF 卡 → eMMC，插卡即自动从 TF 启动，无需按任何键。
若无法从 TF 启动（eMMC 有不兼容固件）：断电 → 按住 Mask 键不松手 → 通电 → 保持 3~5 秒后松开，强制引导。
5
确认 Mac 有线已获取到 IP
系统设置 → 网络 → 以太网，显示"已连接"且有 IP 地址（如 192.168.2.x）即可。
阶段三 确认后台地址并登录
1
打开 Mac 终端，运行以下命令查找网关 IP
netstat -rn | grep default | awk '{print $2}'

输出的 IP 就是 R5C 后台地址，直接在浏览器打开。规律：Mac 拿到的 IP 是 192.168.X.Y，后台就是 192.168.X.1。

192.168.2.1TF 卡临时系统（官方 FriendlyWrt）默认地址
192.168.1.1eMMC ImmortalWrt 刷入后默认地址
2
浏览器访问后台，登录
用户名 root，密码通常为空或 password。
阶段四 将 ImmortalWrt 写入 eMMC
方法一（推荐）：网页后台一键刷入
1
进入 系统 → eMMC 刷机助手
2
上传 ImmortalWrt 固件
点击"浏览"选择之前存入 BOOT 分区的固件，或从 Mac 下载目录选取，点击"开始刷机"。
3
等待进度条 100%，提示写入成功
写入过程中不要断电、不要关闭浏览器，否则 eMMC 可能写入不完整变砖。
方法二（备选）：SSH 命令行写入
1
SSH 连接软路由
ssh root@192.168.2.1
2
确认 eMMC 盘符
lsblk

找容量 32 GB 那个设备，通常是 mmcblk0。

3
执行写入脚本
emmc-install

按提示选择固件路径（之前拷到 BOOT 分区的文件），确认执行。

阶段五 拔卡重启，启动新系统
1
R5C 断电
2
拔掉 TF 卡
不拔卡则下次依然进入 TF 临时系统。
3
重新通电，等待约 30 秒
浏览器访问 192.168.1.1 进入 ImmortalWrt 后台，用户名 root，密码 password。
阶段六 组网：R5C 主路由 + AX82U 作 AP 无线访问后台
光猫 WAN → R5C WAN口 → R5C LAN口 → AX82U LAN口（AP模式）→ Wi-Fi → 设备

AX82U 改 AP 模式：

1
进入 AX82U 后台 192.168.50.1
2
高级设置 → 无线路由器（Operation Mode）→ 切换为 Access Point 模式
切换后 AX82U 的 DHCP 自动关闭，只负责发射 Wi-Fi，IP 分配全交给 R5C。
3
网线接法：R5C 任意 LAN 口 → AX82U 的 LAN 口
AP 模式下接 LAN 口，不是 WAN 口。

无线访问 R5C 后台：

MacBook 连上 AX82U 的 Wi-Fi 后，浏览器直接访问 192.168.1.1 即可管理 R5C，无需插网线。此时不需要关 Wi-Fi，目标 IP 在局域网内，不存在路由冲突。

如需确认后台 IP，连上 Wi-Fi 后在终端运行：

netstat -rn | grep default | awk '{print $2}'

TF 卡保留与重复使用

随时可再次从 TF 引导：断电 → 插入 TF 卡 → 通电，R5C 自动优先从 TF 启动。
回到 eMMC 系统：断电 → 拔掉 TF 卡 → 通电，即可切回。
强烈建议永久保留这张卡作为救砖盘，贴标签注明"R5C 救砖盘"存好。eMMC 系统崩溃时插卡即可修复，节省大量时间。
eMMC 固件大版本升级后，建议同步更新 TF 卡镜像，避免内核版本不兼容。
