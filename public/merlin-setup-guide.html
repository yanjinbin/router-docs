为什么建议从 AX82U 迁移到 RAX80？
AX82U 是 ARMv7 32-bit，偶发的 gcsweep: found pointer to free object 崩溃是 Go runtime 在 ARMv7 平台的已知问题（内存屏障精度不足），与 UDP 配置无关，升级到 ARM64 平台才能根本解决。

udp: false + AND,((DST-PORT,443),(NETWORK,UDP)),REJECT 这两条规则的目的是防止真实 IP 泄露：Gemini、ChatGPT 等 AI 服务会主动发起 QUIC（UDP 443）连接，若不拦截会绕过代理直连，暴露真实 IP 触发风控。代价是 hy2 节点无法使用。

RAX80 是 ARM64，无 gcsweep 崩溃问题，但 UDP 443 REJECT 规则在迁移后仍应保留，除非确认所有 AI 服务流量都已走代理。

刷机步骤
选择对应设备 · AX82U 官方刷机指南 →
🚨 RAX80 固件包含 cfe 引导，绝不能用其他品牌固件强刷。损坏 cfe 只能编程器救砖。
1
从原厂刷入梅林
登录 RAX80 管理界面 → 高级 → 管理 → 固件更新 → 上传 .chk 文件。原厂只认 .chk 格式。
2
梅林升梅林
梅林后台 → 系统管理 → 固件升级 → 上传 .w 文件。梅林间互刷用 .w。
3
刷完恢复出厂
固件刷入后长按 Reset 10 秒恢复出厂，清除旧配置残留。
4
检查 RAX80 Toolbox
进入 koolshare 软件中心，安装 RAX80 Toolbox，可修复旧版本损坏的原厂分区（MAC/SN 恢复）。386.8_1 新刷可跳过。
ℹ 当前跑的是 388.10_2 梅林官方版（无 koolshare 软件中心）。若需装 MC2 需先换回 386.7_2 koolshare 改版。
1
后台升级固件
访问 192.168.2.1 → 系统管理 → 固件升级 → 上传 .w 文件。
2
刷完恢复出厂
固件更新后长按 Reset 10 秒，清除旧配置。
3
重新配置网络
重新填写 PPPoE 拨号账号密码，LAN IP 建议保持 192.168.2.1。
3
MC2 安装
RAX80 用 ARM64，AX82U 用 ARM32，不能混用
1
软件中心 → 离线安装
梅林后台 → 软件中心 → 右上角 离线安装 → 上传 .tar.gz 文件。RAX80 选 ARM64，AX82U 选 ARM32。
2
进入 MC2 初始化
软件中心 → 撸猫魔法云 → 等待初始化完成，内核自动下载对应架构版本。
3
导入 config.yaml
MC2 → 配置文件管理 → 上传完整 config.yaml，所有机场订阅、规则、DNS 一次性生效。
RAX80 迁移时记得去掉 udp: false 和 UDP REJECT 规则，开启 hy2 支持。
4
验证面板
浏览器访问 http://192.168.2.1:9990/ui，用 secret clash 登录 zashboard，确认节点在线。
4

RAX80 迁移差异 · 需修改的配置项
# ── 迁移 RAX80 时需要做的修改 ──────────────────────────────────

# 1. 移除或改为 true（ARM64 无崩溃风险）
udp: true           # 原来是 false，改为 true
prefer-h3: false    # 可按需开启

# 2. 删除 rules 中的这两条
# - IP-CIDR6,::/0,REJECT,no-resolve         # 可保留，继续阻断 IPv6
# - AND,((DST-PORT,443),(NETWORK,UDP)),REJECT  ← 删除此行，hy2 才能工作

# 3. 住宅 IP 节点可加回 udp: true
proxies:
  - {name: "圣何塞静态住宅IP", ..., udp: true, tfo: true, ip-version: ipv4}
  - {name: "东京静态住宅IP", ..., udp: true, ip-version: ipv4}

# 4. external-controller 改为 RAX80 的 LAN IP
external-controller: 192.168.1.1:9990   # 根据你的 LAN IP 调整

# 5. MC2 换 ARM64 包
# MC2_1.0.3_ARM64.tar.gz  （非 ARM32）

刷机前检查清单
点击勾选
  • 已下载对应设备固件（RAX80 用 .chk 或 .w / AX82U 用 .w）
  • 已下载对应架构 MC2（RAX80 → ARM64 / AX82U → ARM32）
  • 已备份当前 config.yaml 到本地
  • 已记录宽带 PPPoE 账号密码
  • 电脑有线连接路由器（勿用 Wi-Fi 刷机）
  • RAX80：原厂固件刷梅林用 .chk，梅林升梅林用 .w
  • 刷机过程中不断电不拔网线
  • 刷完执行恢复出厂（Reset 10 秒）
  • RAX80 迁移：config.yaml 移除 udp: false 和 UDP 443 REJECT 规则
  • MC2 安装后导入 config.yaml，确认订阅 URL 填写正确
  • 浏览器访问 zashboard 面板，验证节点在线
  • IP 检测工具验证出口 IP 正确（ipleak.net / myip.com）
